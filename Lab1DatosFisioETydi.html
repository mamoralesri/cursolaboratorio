La razón de eso son las comas, hay que quitarlas primero, reemplazándolas por punto.

df_limpio <- df |>
  mutate(estatura = estatura|> 
           str_replace(",", ".") |> 
           parse_number(),
         imc=imc|> 
           str_replace(",", ".") |> 
           parse_number())

Ceros a NA

En estadística, confundir un “cero” con un “valor faltante” (NA) es un error grave que sesgaría totalmente cualquier modelo de regresión o promedio.

Código 
df_limpio <- df_limpio |>
  mutate(
    imc = na_if(imc, 0),
    masa_grasa = na_if(masa_grasa, 0),
    masa_muscular= na_if(masa_muscular, 0),
    masa_osea= na_if(masa_osea, 0), 
    grasa_visceral= na_if(grasa_visceral, 0) 
    )

Imputación de datos faltantes

Imputación básica para una variable

Imputaremos imc con la mediana. imc antes de imputar.

   Min. 1st Qu.  Median    Mean 3rd Qu.    Max.    NA's 
  16.80   19.25   21.10   22.50   25.00   33.50       5
Código 
df_limpio<-df_limpio |> mutate(imc = if_else(
    is.na(imc),
    median(imc, na.rm = TRUE), 
    imc
  ))

vars_a_imputar <- c("imc", "masa_grasa", "masa_muscular", "masa_osea", "grasa_visceral")
