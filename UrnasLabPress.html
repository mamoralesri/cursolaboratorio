Lectura de los datos de Urna

Objetivo

Leer y resumir los datos del experimento de la urna

Fijamos el directorio de trabajo

Código 
setwd("~/Documents/Cursos/Laboratorio")

Lectura desde Excel

Código 
library(readxl) 
datos <- read_excel("UrnasLabDatos.xlsx")

Conversión a factores

Tip

No es obligatorio, pero es buena práctica.

Código 
datos$Sexo=factor(datos$Sexo,labels = c("Femenino","Masculino"))
datos$Color=factor(datos$Color,labels = c("Blanco","Verde"))

Tabulación

Código 
with(datos, table(Color,Sexo)) 
        Sexo

Código 
tabla=with(datos, table(Color,Sexo)) 
addmargins(tabla)
